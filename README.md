# VIT Student Academic Support — Desktop Website

A desktop-first website recreation of the supplied reference design, keeping its VIT-inspired branding, Georgia-style headings, red action buttons, pale-red study tip, neutral cards, attendance progress bars, and academic notifications. The UI is arranged as a full-width web portal with a left sidebar rather than a phone mockup.

## Run
Open `index.html` in a modern browser. No dependencies or build tools are required.

## Screens
- Login page
- Dashboard
- Attendance and academics
- Assignments
- Assignment upload
- Academic notifications

## Prototype note
Any non-empty register number and password opens the portal. File selection and validation work client-side; real authentication, student data, and assignment submission require a backend/API.
